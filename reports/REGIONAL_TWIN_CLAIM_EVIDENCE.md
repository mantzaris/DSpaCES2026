## Analysis corrections and remaining gaps

- Historical prose called the detection interval a six-step window. The actual
  comparator includes onset and six subsequent updates. The manuscript specifies
  lag0-6 (seven instants), retaining all original numbers and miss delay7. No replay
  or outcome-driven threshold change occurred.
- Early synthesis draft used full-replay rank changes89/top22. The final script
  explicitly restricts these to the event, reproducing86/17. This is a draft
  bookkeeping fix, not a correction to the preserved Stage 4 report.
- Late changed requests and subthreshold acquired scores explain the observed
  localization count. Why M3b has slightly worse forecast error than M3 is not
  causally identified: changed histories, background-dominated ranking and fixed
  model misspecification remain possible. No beneficial replacement is inferred.
- A streamed fine model can answer local queries using summaries and ephemeral
  conditionals. The measured saving against full retention is not a unique
  refinement capability. Single-window factor reuse does not imply locality when
  the window advances; the sequential code rebuilds every group.
