The adjacent regional-energy-twin project concerns Gaussian state refinement and measurement acquisition, not these repair tests. No numerical results are reused.

## Implementation findings

GDN revision `9853899da860682669a134e4af315d036aab4eca` is MIT licensed. Its `evaluate.py:get_err_scores` computes median/IQR from its test arguments, despite receiving validation arguments. `get_best_performance_data` searches thresholds using test labels. Both behaviors are replaced by a clearly labeled common evaluation protocol. Dense attention preserves the inspected one-head model operations.

DiffAD revision `a05f764dea8c956c0dc95802d4a2813a70a7144e` has no root license file. Downloaded code remains an untracked research cache. The supplied `sr3_modules/unet.py` implements convolutional residual blocks and attention, while `diffusion.py` uses conditioning concatenation. The inspected files do not implement the paper's S4 blocks or increasing replacement weights. Do not label a run of that snapshot a verified full paper reproduction. Resolve this discrepancy through an explicitly documented paper implementation or a distinct comparator label before final claims.

CSDI revision `7f24a436f08d98853a6b43d4f7f04e5a65ecdf27` includes a license. Its full method uses temporal and feature Transformer layers. Our compact graph-conditioned diffusion is a separate architecture using the established masked denoising objective, not a claim of exact CSDI reproduction.

The independent DiffAD adaptation now implements joint diagonal-Gaussian density-ratio selection, bicubic conditioning, a three-scale S4 U-Net, the paper's integer-step exponential replacement weight and all 100 reverse steps. The density estimator, selection floors, dense stable S4 parameterization, 64-step windows, common preprocessing and learning-rate selection are explicit adaptations. This is labeled a DiffAD adaptation, not an exact author-code reproduction. Dense state-space convolution is checked against a separately written state recurrence. A training-only stability audit checks the learned discrete poles.

Liu and Paparrizos, [TSB-AD, NeurIPS 2024](https://proceedings.neurips.cc/paper_files/paper/2024/hash/c3f3c690b7a99fba16d0efd35cb83b2c-Abstract-Datasets_and_Benchmarks_Track.html), was also reviewed through its dataset construction, label assessment and evaluation sections. It motivates explicit label scope, simple baselines and avoiding point-adjusted scores. The present study uses fixed controlled events and separate native event metrics rather than presenting itself as a replacement broad benchmark.
